# uQUIC — форк Labpics

Библиотека на Go для настройки QUIC Initial и TLS ClientHello.
Этот репозиторий развивает [uQUIC](https://github.com/refraction-networking/uquic),
основанный на [quic-go](https://github.com/quic-go/quic-go). Спецификация позволяет
задавать заголовок Initial, построение фреймов и параметры ClientHello. Настройка
отпечатка не гарантирует неотличимость от браузера или доступность в заданной сети.

## Первый проверяемый сценарий

Требование к Go задаёт [go.mod](go.mod), а не номер в README или название
комбинации CI. Используйте совместимый установленный toolchain. Начните с
checkout именно этого форка:

```sh
git clone https://github.com/Labpics-Team/uquic.git
cd uquic
go test -count=1 -run '^ExampleCurrentChromeParrot$' .
```

[Исполняемый пример](example_documentation_test.go) получает выбранный библиотекой
профиль через `CurrentChromeParrot()`, разрешает его через `QUICID2Spec()` и
проверяет наличие ClientHello. Он не устанавливает внешнего соединения и не
проверяет актуальность браузерного эталона. Изменение публичной сигнатуры или
неразрешимый профиль нарушают этот пример и штатный Go-тест.

У модуля сохранено имя `github.com/refraction-networking/uquic`. Установка этого
имени из upstream не выбирает автоматически Labpics-форк. Привязку зависимости
к форку потребитель объявляет в своём `go.mod` и проверяет через
`go list -m -json github.com/refraction-networking/uquic`.
Этот репозиторий не меняет конфигурацию потребителя скрыто.

## Документация

[Выбор и обновление отпечатка](docs/ametyst-integration.md) разделяет контракт
идентификатора, проверку сохранённого эталона и новое внешнее наблюдение.
[HTTP/3](http3/README.md) описывает актуальный транспорт и владение ресурсами.
[Локальная диагностика метрик](metrics/dashboards/README.md) объясняет настройку
проверочного стенда, не production-развёртывания.

Для локальной проверки исходников:

```sh
go build ./...
go test -count=1 ./ci
go test -count=1 ./...
```

Последняя команда включает интеграционные пакеты и их зависимости от среды.
Точные окружения штатных удалённых проверок определены в
[Go Build](.github/workflows/go_build.yml),
[unit-проверках](.github/workflows/ginkgo_test.yml) и
[интеграционных проверках](.github/workflows/integration.yml).
Успех отдельной команды не заменяет обязательный итоговый CI.

## Границы гарантий

Это исследовательская библиотека. Унаследованное предупреждение о неготовности
к production сохраняется: этот форк не объявляет независимого научного ревью
или аудита, которые снимали бы такое ограничение.

Нормализованный отпечаток проверяет только перечисленные поля сохранённого
наблюдения. Он не доказывает равенство всего сетевого поведения: порядка
фреймов, временных характеристик, реакций на Retry или поведения приложения.
Подражание неподходящему профилю может само повысить различимость.
Использование для обхода цензуры требует учитывать эти ограничения, а не
принимать зелёный тест за гарантию безопасности канала.
