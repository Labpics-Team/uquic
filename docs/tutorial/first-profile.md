# Первый профиль без внешней сети

Цель — получить спецификацию выбранного Chrome-профиля и увидеть, что публичный
API форка разрешает её без сетевого соединения.

## 1. Получите checkout

```sh
git clone https://github.com/Labpics-Team/uquic.git
cd uquic
```

Требование к Go задаёт `go.mod`. Используйте совместимый toolchain; README не
дублирует его номер.

## 2. Запустите исполняемый пример

```sh
go test -count=1 -run '^ExampleCurrentChromeParrot$' .
```

Тест выполняет [`ExampleCurrentChromeParrot`](../../example_documentation_test.go).
Он вызывает публичные `CurrentChromeParrot()` и `QUICID2Spec()` и ожидает
ненулевой `ClientHelloSpec`.

## 3. Интерпретируйте результат правильно

Успех означает, что выбранный этой версией библиотеки идентификатор разрешается
в спецификацию. Сетевого запроса к Chrome нет: тест не подтверждает свежесть
внешнего браузерного отпечатка, неотличимость всего QUIC-трафика или доступность
в конкретной сети.

Дальше используйте [справку профиля](../reference/browser-profile.md), а для
проверки всего checkout — [отдельную инструкцию](../how-to/verify-checkout.md).
