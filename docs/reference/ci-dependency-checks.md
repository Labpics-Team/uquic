# Проверка графа зависимостей в CI

Исключение GO-2026-5932 допустимо, пока `golang.org/x/crypto/openpgp` отсутствует
в производственных и тестовых зависимостях проверяемых ОС, архитектур и cgo.

Проверка исполняет Bash из workflow и наблюдает вызовы `go list`: полный набор
пакетов, зависимости тестов, каждая требуемая платформа. Не удалось построить
граф или обнаружен запрещённый пакет — CI завершается ошибкой. Список платформ
в тесте независим от проверяемого скрипта: удаление платформы не делает тест
зелёным. Версия Go для подготовки графа следует минимальной версии из `go.mod`.

Имена шагов, время ожидания и обновления закреплённых actions не меняют этого
свойства. YAML anchors и aliases разбирает `yaml.v3`; проверяются их значения.
Слияние YAML, неизвестные теги, повторные ключи и дополнительные документы
отклоняются. Локальная команда: `go test -count=1 ./ci`.
