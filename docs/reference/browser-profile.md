# Браузерный профиль — справка

`CurrentChromeParrot()` возвращает `QUICID`, выбранный текущим исходным кодом.
Конкретное значение не дублируется здесь: его задаёт
[`u_parrot.go`](../../u_parrot.go), а [`u_parrot_test.go`](../../u_parrot_test.go)
проверяет разрешимость через `QUICID2Spec()`.

`QUICID2Spec(id)` строит `QUICSpec` либо возвращает ошибку для неизвестного ID.
В Chrome-профилях порядок TLS-расширений перемешивается при **построении
спецификации**. `ApplyPreset` использует уже построенный порядок. Поэтому
повторное использование одной `QUICSpec` не означает новую перестановку на
каждом соединении.

Потребитель может использовать accessor либо фиксированный `QUICID`. В обоих
случаях версия зависимости остаётся его явным выбором. Module path
`github.com/refraction-networking/uquic` общий с upstream и сам по себе не
указывает на Labpics-форк; фактический источник модуля проверяется через
`go list -m -json github.com/refraction-networking/uquic` в проекте-потребителе.

Нормализованный fingerprint сортирует часть данных и не является проверкой
порядка всех значений на проводе. Область differential assertions описана в
[объяснении evidence](../explanation/browser-evidence.md).
