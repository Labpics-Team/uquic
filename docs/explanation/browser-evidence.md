# Что доказывает сохранённый browser evidence

[`u_parrot_differential_test.go`](../../u_parrot_differential_test.go) формирует
локальный QUIC Initial, разбирает его через `clienthellod` и сравнивает
нормализованный fingerprint, отдельные поля ClientHello и transport parameters
с сохранённым наблюдением.

Такой тест отвечает на вопрос: «совпадает ли текущая реализация с этим
закреплённым наблюдением в перечисленной области сравнения?» Изменение кода,
нарушающее соответствие, должно сделать тест красным.

Он **не** отвечает на другой вопрос: «соответствует ли сохранённый снимок
последнему Chrome сейчас?». Новый выпуск браузера не меняет байты в Git и не
может сам вызвать падение локального теста. Для свежести требуется новое
независимое наблюдение по процедуре обновления.

Нормализация также теряет часть порядка. Совпадение итогового хеша не доказывает
полного равенства frame layout, таймингов, Retry-поведения, всех transport
parameter values или эквивалентности другой fingerprinting-системе. Поэтому в
тесте сохранены отдельные assertions там, где нормализованный идентификатор
недостаточен.

Это различие не ослабляет регрессионный тест: оно ограничивает вывод ровно той
областью, которую тест способен фальсифицировать.
